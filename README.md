# Azure Hands-on Projects

This repository documents my hands-on Azure learning path as a junior cloud consultant.

## Goal

Build practical Azure skills using a free-tier-first approach, with clear documentation, screenshots, cleanup proof, and GitHub-ready project structure.

## Projects

1. Resource Group and Storage Foundation
2. Static Website with Azure Storage
3. Linux VM Web Server
4. Serverless Function API
5. Event-driven Blob Processing
6. Container App Deployment
7. Monitoring and Alerts
8. Terraform Azure Foundation

## Cost Safety

This path is designed to use Azure Free Tier where possible. Paid resources should be deleted immediately after each lab.
